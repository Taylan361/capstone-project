# Demo project fixture

This folder contains synthetic, intentionally insecure code used only to test AICodeShield's read-only scanning and reporting features. The placeholder credential is not real. Do not install dependencies, execute the files, or deploy this fixture.

The source includes examples of dynamic evaluation, shell-enabled command execution, child-process execution, and a secret-like assignment. The manifests provide sample Python and Node.js dependencies for inventory. Optional online dependency lookup is disabled by default and contacts public package/advisory services only when explicitly enabled in the dashboard.
